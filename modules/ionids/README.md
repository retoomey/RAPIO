# ionids: NOAA NEXRAD Level III (NIDS) I/O Module

The `ionids` (`rapionids`) module provides modern C++17 support for reading and decoding NOAA/NWS NEXRAD Level III (NIDS — NEXRAD Information Dissemination Service) radar products within the **RAPIO** framework. It parses WMO/AWIPS-framed or raw NIDS binary messages into standard `rapio::RadialSet` and `rapio::DataTable` objects for downstream meteorological processing and format conversion (e.g., to NetCDF).

## Overview

NEXRAD Level III (NIDS) products are generated by the WSR-88D Radar Product Generator (RPG) and distributed via NOAA, NCDC/NCEI archives, NOAAPORT, and NWS FTP/LDM feeds. Unlike Level II base data, Level III products are product-specific (e.g., 8-bit 256-level digital reflectivity/velocity, dual-polarization products, and storm-cell/algorithm tables) and are not fully self-describing—requiring an external product table to map product codes to units, gate resolution, compression, and threshold decoding rules.

`ionids` integrates Level III ingest into RAPIO as a dynamically loadable `IODataType` plugin (`librapionids.so`, registered as `"nids"` in `RAPIOConfig/rapiosettings.xml`), offering:
1. **Automatic Bulletin Header Stripping**: Detects and skips up to two leading WMO/AWIPS text headers (`\r\r\n` / `\r\n`) before parsing binary NIDS blocks.
2. **Table-Driven Product Configuration**: Uses `misc/NIDSProdInfo.xml` via `ConfigNIDSInfo` to look up product metadata, compression flags, and threshold scaling methods.
3. **Modular Block & Specializer Architecture**: Separates binary NIDS block parsing (`BlockMessageHeader`, `BlockProductDesc`, `BlockProductSymbology`, `BlockRadialSet`) from `NIDSSpecializer` implementations for `RadialSet` and `DataTable` products.

## Key Capabilities & Product Support

### 1. Bulletin Framing & NIDS Block Decoding
- **WMO / AWIPS Header Removal (`IONIDS::readHeaders`)**: Scans past up to two ASCII bulletin headers (e.g., `SDUS82 KGSP 082001` / `NYX GSP`) terminated by `0x0D 0x0D 0x0A` (or `0x0D 0x0A`).
- **Big-Endian Binary Blocks**:
  - `BlockMessageHeader`: Reads the 18-byte message header (message code, Julian date, seconds past midnight GMT, message length, source/destination IDs, block count) and validates that `myMsgLength` matches the payload size (tolerating trailing padding bytes).
  - `BlockProductDesc`: Reads the Product Description Block, extracting radar `LLH` coordinates, product code, operational mode, VCP, sequence/volume scan numbers, volume start and generation `Time`s, 16 encoded data threshold values, and 10 product-dependent parameters (`dep[1..10]`).
  - `BlockProductSymbology`: Validates the `-1` block divider and parses block ID, block length, and layer count.
- **Transparent BZIP2 Decompression**: When `compress="yes"` is set for the product code in `misc/NIDSProdInfo.xml`, the symbology payload following `BlockProductDesc` is automatically decompressed via `StreamBuffer::readBZIP2()` before symbology/product decoding.

### 2. Radial Products (`RadialSet`)
Implemented by `NIDSRadialSet` (registered for `"RadialSet"`, `"PolarGrid"`, `"SparseRadialSet"`, and `"SparsePolarGrid"`):
- **Supported Symbology Packets**:
  - **Packet `0xAF1F` (`-20705`)**: Run-Length Encoded (RLE) radial data (`NIDSUtil::getRLEColors`).
  - **Packet `16` (`0x10`)**: Digital Radial Data Array (`NIDSUtil::getColors`).
  - **Packet `1`**: Text/Symbol null-product layer (`BlockRadialSet::isNullPacket()`), handled cleanly by returning a `Constants::MissingData`-filled `RadialSet`.
- **Null Product Handling**: Precipitation accumulation products (`31`, `169`–`173`, `175`) check the RPG null-product flag in `dep[3]` (`dep[3] & 0x00FF` for `173`) as well as Packet `1` symbology layers. When in a null state, `NIDSRadialSet` returns a valid `RadialSet` with geometry derived from `NIDSProdInfo.xml` filled with `Constants::MissingData`; when `nullFlag == 0` and radial data is present, radials are decoded normally.
- **Threshold & Value Conversion (`NIDSUtil`)**:
  - **Decoded Threshold Methods (`D1`–`D4`)**: Converts raw color codes to physical floating-point values using decoded thresholds (covering products such as `94`, `99`, `153`, `154`, `155`, `159`, `161`, `163`, `164`, `165`, `176`, `177`).
  - **Encoded Threshold Methods (`E1`–`E3`)**: Uses direct encoded thresholds for products `134`, `135`, and `176`.
- **Output Geometry & Attributes**: Populates a `rapio::RadialSet` with `TypeName`, `Units`, `LLH` location, `Time` (volume start time), elevation angle (`dep[3] * 0.1`, `0.0°` for null-capable precipitation products, or unscaled for product `84`), VCP, `firstGateDistanceMeters`, uniform `GateWidth`, per-radial `Azimuth`, `BeamWidth` (`1.0°` with `AzimuthSpacing` for super-res products `153`–`155`), and padded `Constants::MissingData` gates.

### 3. Storm & Algorithm Table Products (`DataTable`)
`ionids` registers and decodes all seven tabular/symbology NIDS algorithm outputs into rectangular `rapio::DataTable` objects:

| Specializer Class | Registered `DataType` Names | Typical NIDS Code | Description |
|:---|:---|:---:|:---|
| `NIDSSTITable` | `OrpgStormTrackInfo`, `StormTrackInfo` | `58` | Storm Tracking Information (cell IDs, positions, motion) |
| `NIDSHailIndexTable` | `OrpgHailIndex`, `HailIndex` | `59` | Hail Index (Packet 8 hail probability & max hail size) |
| `NIDSMesoTable` | `OrpgMeso`, `OrpgMesoTable` | `60` | Legacy Mesocyclone product |
| `NIDSTVSTable` | `OrpgTVSTable`, `TVS` | `61` | Tornado Vortex Signature (TVS / ETVS) attributes |
| `NIDSStormStructureTable` | `OrpgStormStructure`, `StormStructure` | `62` | Storm Structure / Cell Trend data (Packet 22 scan times & cell trend packets) |
| `NIDSMesoDetectionTable` | `OrpgMesoDetection`, `OrpgMesoDetectionTable` | `141` | Mesocyclone Detection Algorithm (MDA) table |
| `NIDSStormCellTable` | `OrpgStormCellTable`, `StormCellTable` | — | Storm Cell tabular data (Packet 8 multi-page parsing) |

### 4. Product Metadata Lookup (`misc/NIDSProdInfo.xml`)
`ConfigNIDSInfo` lazily loads `misc/NIDSProdInfo.xml` via `Config::huntXML()` and indexes `<info>` entries by `code`:
- `type`: Output RAPIO `TypeName` (e.g., `Reflectivity`, `Velocity`, `SpectrumWidth`, `OrpgTVSTable`)
- `res` & `range`: Resolution and range used to compute gate width in meters, beamwidth in degrees, and null-product gate counts
- `units`: Meteorological units (e.g., `dBZ`, `kt`, `meters/sec`, `dimensionless`)
- `datatype`: Target RAPIO `DataType` (e.g., `RadialSet`, `OrpgTVSTable`)
- `compress`: `"yes"` if the symbology payload is BZIP2-compressed
- `decode`, `min`, `increase`: Threshold decoding method selector and scaling parameters

## Software Architecture

```
RAPIO/
├── RAPIOConfig/
│   ├── rapiosettings.xml                   --> Registers <io names="nids" module="librapionids.so">
│   └── misc/
│       └── NIDSProdInfo.xml                --> NIDS product code lookup database
└── modules/ionids/
    ├── rIONIDS.h / .cc                     --> Dynamic RAPIO plugin (IODataType: "nids") & WMO/AWIPS header skipper
    ├── rNIDSSpecializer.h                  --> Base interface for NIDS DataType readers/writers
    ├── rConfigNIDSInfo.h / .cc             --> Lazy XML loader & lookup table for NIDSProdInfo.xml
    ├── rNIDSUtil.h / .cc                   --> NIDS time conversion, RLE/color unpacking, D1-D4 / E1-E3 value scaling
    ├── rBlockMessageHeader.h / .cc         --> 18-byte NIDS Message Header Block parser/writer
    ├── rBlockProductDesc.h / .cc           --> NIDS Product Description Block parser/writer
    ├── rBlockProductSymbology.h / .cc      --> NIDS Product Symbology Block parser/writer
    ├── rBlockRadialSet.h / .cc             --> Radial symbology packet (0xAF1F / 16 / 1) parser/writer
    ├── rNIDSRadialSet.h / .cc              --> RadialSet reader/writer specializer
    ├── rNIDSSTITable.h / .cc               --> Storm Track Info (code 58) DataTable specializer
    ├── rNIDSHailIndexTable.h / .cc         --> Hail Index (code 59) DataTable specializer
    ├── rNIDSMesoTable.h / .cc              --> Mesocyclone (code 60) DataTable specializer
    ├── rNIDSTVSTable.h / .cc               --> TVS (code 61) DataTable specializer
    ├── rNIDSStormStructureTable.h / .cc    --> Storm Structure (code 62) DataTable specializer
    ├── rNIDSMesoDetectionTable.h / .cc     --> MDA (code 141) DataTable specializer
    ├── rNIDSStormCellTable.h / .cc         --> Storm Cell DataTable specializer
    └── rTestNIDS.cc                        --> Boost.Test unit test suite
```

## Operations & Deployment Examples

### Building
```bash
cd /path/to/RAPIO
mkdir -p BUILD && cd BUILD
cmake .. -DCMAKE_BUILD_TYPE=RelWithDebInfo -DRAPIO_BUILD_TESTS=ON
cmake --build . -j$(nproc)
```
Artifacts:
- Shared Library: `BUILD/lib/librapionids.so`
- Unit Test Binary: `BUILD/bin/rTestNIDS`

### Environment Configuration
Ensure `RAPIO_CONFIG_LOCATION` (or `W2_CONFIG_LOCATION`) points to your configuration directory containing `rapiosettings.xml` and `misc/NIDSProdInfo.xml`:
```bash
export RAPIO_CONFIG_LOCATION=/path/to/RAPIO/RAPIOConfig
```

### Programmatic API Usage (RAPIO C++)
```cpp
#include <rRAPIORuntime.h>
#include <rIODataType.h>
#include <rIOConfig.h>
#include <rRadialSet.h>
#include <rDataTable.h>

int main() {
  rapio::RAPIORuntime::initialize();

  rapio::IOConfig config;
  config.setParams("/path/to/KOUN_SDUS54_N0Q_202512011200");

  auto dt = rapio::IODataType::read("nids", config);
  if (auto rs = std::dynamic_pointer_cast<rapio::RadialSet>(dt)) {
    // Process Level III RadialSet...
  } else if (auto tbl = std::dynamic_pointer_cast<rapio::DataTable>(dt)) {
    // Process Level III storm/algorithm DataTable...
  }
  return 0;
}
```

## Verification & Unit Tests

The unit test suite in `rTestNIDS.cc` validates block parsing, null-product radial handling, and table decoding across 10 tests:
1. `TestNIDSMessageHeaderDecoding`: Big-endian 18-byte `BlockMessageHeader` parsing and validation.
2. `TestNIDSProductDescDecoding`: `BlockProductDesc` parsing, location, VCP, timestamps, thresholds, and dependent fields.
3. `TestNIDSTVSTableDecoding`: TVS (`OrpgTVSTable`) table decoding.
4. `TestNIDSSTITableDecoding`: Storm Tracking Information (`OrpgStormTrackInfo`) table decoding.
5. `TestNIDSMesoTableDecoding`: Mesocyclone (`OrpgMeso`) table decoding.
6. `TestNIDSMesoDetectionTableDecoding`: Mesocyclone Detection Algorithm (`OrpgMesoDetection`) table decoding.
7. `TestNIDSStormStructureTableDecoding`: Storm Structure (`OrpgStormStructure`) Cell Trend Packet 22 decoding.
8. `TestNIDSStormCellTableDecoding`: Storm Cell (`OrpgStormCellTable`) Packet 8 multi-page decoding.
9. `TestNIDSHailIndexTableDecoding`: Hail Index (`HailIndex`, code `59`) Graphic Alphanumeric Packet 8 decoding.
10. `TestNIDSNullProductRadialSetDecoding`: Null product (`170` / `dep[3]` & Packet `1`) `RadialSet` decoding filled with `Constants::MissingData`.

Run via CTest or directly:
```bash
ctest --test-dir BUILD -R NIDS --output-on-failure
./BUILD/bin/rTestNIDS --log_level=test_suite
```
